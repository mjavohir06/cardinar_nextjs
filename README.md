# Cardinar — frontend

[Cardinar.uz](https://cardinar.uz) avto gilamcha va avto qoplamalar onlayn do'koni.
Backend: [cardinar_nestjs](https://github.com/mjavohir06/cardinar_nestjs)

**Texnologiyalar:** Next.js (App Router), React, TypeScript, Tailwind CSS, next-intl (ko'p tilli), Axios

## Sahifalar
- Bosh sahifa, do'kon va mahsulot sahifasi
- **Gilamcha konstruktori** — mashina modeli bo'yicha gilamcha yig'ish
- Savat, ro'yxatdan o'tish / kirish, aloqa

## Ishga tushirish

```bash
npm install
npm run dev
```
